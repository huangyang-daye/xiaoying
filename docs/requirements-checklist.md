## 已知限制与可选扩展

- 未提供任务取消、失败重做、单条记录/素材删除或专用下载按钮；原题仅要求成功图片可预览。删除账户会清理所属记录和对应文件。
- 已提供请求头幂等、阶段检查点续跑、有限自动重试及过期租约恢复；协议和边界见[可靠性方案](task-reliability.md)。不带键的旧调用、外部副作用 exactly-once、无限重试及最终失败的原地重做不在保证内。
- 未提供孤立文件自动回收、邮箱验证、忘记密码、配额或多 Java 实例协调。
- 真实 AI、支付、会员、第三方登录、复杂运营后台、集群和消息队列运维不属于本题范围。
- ACID 覆盖数据库记录与新本地生成结果，不覆盖文件系统与外部 URL 的分布式事务。
