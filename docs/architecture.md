# 当前架构与系统边界

更新日期：2026-11-02。并发事务基线：`730d70d3ff55b1c2601a8b51162b3e00c1c69371`；本次提交继续增加 V7 可靠性扩展。本文描述当前代码；早期候选设计保留于[实现规划](implementation-plan.md)和[参数字典](parameter-catalog.md)。

## 组件与职责

| 组件 | 当前职责 |
| --- | --- |
| Next.js App Router | 模板列表/详情、自建模板、上传、任务与历史、登录注册和个人设置；通过同源代理访问 Java |
| Java / Spring Boot | 账户会话、模板与素材校验、任务受理、后台工作池、状态机、结果权限 |
| MyBatis / MySQL 8.4 | 保存账户、模板、素材元信息、任务、素材顺序、阶段和新结果字节、幂等键、租约与执行尝试 |
| 后端文件卷 | 保存上传图片、示例图、头像及 V6 前的文件结果 |

```text
浏览器 → Next.js /api、/files 代理 → Java API → MyBatis → MySQL
                                     ↓
                               后端文件数据卷

POST 制作 → 受理事务提交 QUEUED → HTTP 202 返回 taskId
                                   ↓
                       调度线程派发空闲执行机会
                                   ↓
                 工作线程锁定并认领数据库任务
                                   ↓
                 素材检查 → 模拟生成 → 结果整理
                                   ↓
                     短事务更新步骤、任务及结果
```

业务执行与持久化由 Java 承担，浏览器关闭或 Next.js 重启不会中断后台任务。查询接口只读，不推动任务执行。

## 身份与资源归属

Java 使用服务端 HttpSession 和 HttpOnly、SameSite=Lax Cookie；会话保存账户 ID，每次从数据库读取当前资料。支持注册、用户名/邮箱密码登录、公开 A/B 演示账户、修改昵称/头像/密码及删除账户。密码使用 PBKDF2-HMAC-SHA256 存储。

素材、任务和结果按账户归属校验，自建模板仅创建者可见。公共种子模板与示例图公开访问，个人结果需会话权限。演示账户是共享身份，不等同于私有账户。尚未提供邮箱验证、忘记密码或完整生产账号运营能力。

## 队列与状态

数据库 QUEUED 记录是持久化待执行队列，默认 4 个工作线程并行，可通过 TASK_WORKER_CONCURRENCY 配置 1～32。工作池不缓存业务任务，满载时新任务继续留在数据库。每个任务内部仍顺序执行三个阶段。

整体状态为 QUEUED、RUNNING、SUCCEEDED、FAILED。阶段有独立步骤记录；失败后续步骤为 SKIPPED。每任务独立轮询，终态停止；查询异常保留上次状态并允许手动恢复。刷新时从服务端重建历史和活动任务，活动列表使用 nextCursor/before 游标避免并行完成导致分页遗漏。

## 事务与存储

受理事务创建任务、素材关联和步骤。工作线程使用 READ_COMMITTED 与 FOR UPDATE SKIP LOCKED 认领；阶段和失败更新先锁任务父行，再写步骤，并校验任务版本。耗时等待和图片准备位于事务外。历史与详情使用 REPEATABLE_READ 获取一致快照。

V6 新增 task_result，结果字节与最终步骤、SUCCEEDED 状态原子提交；旧 result_key 文件结果继续兼容读取。账户删除先锁账户及所属任务；新结果通过外键级联删除，文件仅在删除事务提交后清理。具体 ACID 约束和回滚场景见[一致性设计](async-consistency.md)。

数据库事务不覆盖上传文件、旧结果文件或外部图片站点，不承诺跨资源分布式原子提交。持久化依赖 InnoDB、可靠存储及保留数据卷，运维仍需备份。

## 部署与恢复边界

Compose 提供一个 Next.js、一个 Java 和一个 MySQL 服务。浏览器 API 和图片经同源代理访问；端口、允许来源、密码及并发配置见[启动说明](../README.md#快速启动)和[后端配置](../backend/README.md#配置)。Flyway 顺序执行 V1～V7，不修改已执行迁移。

当前只支持单 Java 实例内并发。Java 启动及周期扫描恢复过期 RUNNING，有效租约不受影响；QUEUED 按持久化到期时间执行。幂等受理使用账户作用域唯一键，暂时性故障按指数退避和全局预算重试，已成功阶段不重做；会话失效后重新登录可读历史。数据库恢复后可继续扫描。租约/令牌保护数据库提交，但完整多实例文件共享、会话路由和集群运营尚未验收。升级和回滚必须同时考虑 V6 新结果格式，不能直接用旧程序读取新结果。

## 可靠性扩展

按用户＋Idempotency-Key 唯一受理并保存规范化请求指纹。同键相同参数重放原任务，不同参数返回 409；省略键的旧调用不提供去重。网站保存未确认意图，刷新后可恢复。

每次认领生成新令牌并写执行历史，心跳续租。阶段更新检查令牌及租约期限；到期恢复保留已提交阶段，并消耗同一任务的总尝试预算。next_attempt_at 驱动到期调度，不占工作线程等待退避。最终失败和成功均为终态。

方案比较、错误分类、协议与限制见[任务可靠性设计](task-reliability.md)。
